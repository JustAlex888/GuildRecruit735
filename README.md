# GuildRecruit735

**Версия 1.0.0** · WoW **Legion 7.3.5** · Interface **70300** · Лицензия **MIT**

GuildRecruit735 — самостоятельный аддон для **ручного подбора игроков в гильдию**. Основной проверенный сценарий — **Legion Plus / UWoW x1**. Аддон не является форком SuperGuildInvite и не содержит его исходников, библиотек или графики.

[English documentation](README.en.md) · [История](CHANGELOG.md) · [Ограничения](docs/KNOWN_LIMITATIONS.md) · [Лицензия](LICENSE)

## Возможности

- Сканирование `/who` **по команде пользователя**: заданный диапазон уровней, ограниченное число запросов, счётчики ответов и найденных кандидатов. Список игроков выбирается вручную — массового приглашения нет.
- Фильтры по имени и классам. Именной каталог общий для WoW-аккаунта; включение исключений индивидуально для персонажа и гильдии.
- Режимы Hardcore (исключать / только HC / все) с осторожным обращением к неопределённому статусу. World ID 44 — настройка первого целевого мира x1.
- По клику по кандидату: только приглашение, **личное сообщение → приглашение**, либо только личное сообщение. Шесть редактируемых шаблонов с `{player}`, `{guild}`, `{level}`, `{class}` и безопасной проверкой длины в байтах.
- Ограничение повторных **попыток контакта** на 30 дней, подтверждаемый сброс для текущего профиля.
- Круглая кнопка возле мини-карты (в том числе с MinimapButtonBag): ЛКМ — главное окно, ПКМ — настройки.
- Русский и английский интерфейс, выбор языка клиента автоматически или командой.

## Установка

1. Полностью закройте World of Warcraft.
2. Сохраните резервную копию своих файлов `GR735DB.lua` и `GR735CharDB.lua` из WTF (на всякий случай); **не удаляйте WTF/SavedVariables**.
3. Распакуйте установочный архив так, чтобы получилось `World of Warcraft/Interface/AddOns/GuildRecruit735/GuildRecruit735.toc`. Если обновляете более раннюю сборку, замените только папку аддона `GuildRecruit735`.
4. Запустите WoW и откройте аддон кнопкой мини-карты или `/gr735`. Для проверки выпуска используйте `/gr735 version` (ожидается `1.0.0 / GR735-20261014-03`).
5. Запустите сканирование вручную. Для реальных приглашений выбирайте игроков по одному.

## Команды

| Команда | Действие |
| --- | --- |
| `/gr735` | Открыть/закрыть главную панель |
| `/gr735 version` | Показать версию и ID сборки |
| `/gr735 options` | Настройки |
| `/gr735 scan` / `/gr735 stop` | Запустить/остановить сканирование |
| `/gr735 filters` / `/gr735 messages` | Фильтры / шаблоны |
| `/gr735 minimap` | Скрыть/вернуть кнопку мини-карты |
| `/gr735 resetcontacts` | Подтвердить очистку истории контактов текущего профиля |
| `/gr735 lang ru`, `/gr735 lang en`, `/gr735 lang auto` | Выбрать русский, английский или язык клиента. После команды выполнить `/reload` |

## Сохранение настроек и локализация

`GR735DB` и `GR735CharDB` остаются совместимыми с собственными предыдущими версиями GuildRecruit735. Язык интерфейса не меняет уже введённые шаблоны, фильтры и имена игроков. Серверные названия классов/рас/гильдий из WHO не переводятся. Другие клиентские языки используют английский интерфейс по умолчанию.

## Поддержка и ограничения

Функциональные подтверждения на x1 были получены в предрелизных игровых тестах: круглая мини-кнопка, нажатия ЛКМ/ПКМ, ручная выдача результатов WHO и поступившие адресату whisper + приглашение. Английская локализация и девять кандидатов показаны в `GAME_TEST_005` на версии `0.1.5-TEST`. Это не означает, что **все** HC-режимы, все сценарии WHO, `/reload`, x100 и межсерверная фильтрация проверены. Подробнее — [известные ограничения](docs/KNOWN_LIMITATIONS.md).

**Происхождение:** оригинальная реализация без заимствования кода SuperGuildInvite, Guild Control, DBM, WeakAuras, ExRT и Oilvl. MIT применяется к исходникам аддона; изображения игрового интерфейса содержат материалы игры World of Warcraft и не объявляются объектами MIT-лицензии. Никакой автоматической рекламы и массовых рассылок.
