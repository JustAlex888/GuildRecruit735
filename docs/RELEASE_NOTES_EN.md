# GuildRecruit735 v1.0.0 — Release notes

**WoW Legion 7.3.5 / Interface 70300** · **Build `GR735-20261014-03`** · **MIT license**

The first release of an independent, **manual** guild recruitment addon. Narrow user game evidence on Legion Plus x1 confirms the minimap icon's L/R-click behavior, manual WHO candidate display, a received guild invitation plus whisper on the second client, and a visually functional English UI across five principal windows. These observations are from versions `0.1.4-TEST` and `0.1.5-TEST`; **no independent full 1.0.0 game run** is claimed.

**Features:** bilingual RU/EN, manual bounded WHO, name/class filters, three HC modes, three deliberate invitation/whisper actions, six templates, a 30-day attempted-contact cooldown and round minimap button. No automated or bulk invitations.

**Install:** extract `GuildRecruit735-1.0.0-GR735-20261014-03.zip` into `Interface/AddOns/`, retain all WTF/SavedVariables, use `/gr735 version` to confirm.

**Exact delta:** version/packaging/documentation promotion from 0.1.5; no gameplay Lua change. Original code and bundled MIT license. `x100` and cross-realm filtering are **not verified and not claimed supported**. HC world ID 44 is the x1 configuration.

**Install archive SHA-256:** see `GR735-20261014-03_MANIFEST.json` generated by the build.
