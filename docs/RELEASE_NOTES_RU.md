# GuildRecruit735 1.0.2 — релиз

**WoW Legion 7.3.5 / Interface 70300** · **Сборка `GR735-20261015-01`** · **MIT**.

Исправления после 1.0.0:

- **Диапазон поиска:** введённые уровни сохраняются без обязательного нажатия на отдельную кнопку «Сохранить». Enter, уход с поля и закрытие настроек также сохраняют корректные значения. Например, диапазон `10–90` применяется к следующему ручному WHO.
- **История контактов:** игроки, которым уже отправлялось приглашение либо личное сообщение, не попадают в повторный список кандидатов в течение 30 дней. Истечение срока и подтверждённый сброс истории по-прежнему работают.
- **Меню настроек:** выбор режима HC и способа контакта реализован собственными элементами вместо общих `UIDropDownMenu` Blizzard. Это уменьшает риск загрязнения защищённых рейдовых фреймов, но **полное устранение ошибки `CompactRaidFrame*:Show()` в игре не доказано**.

**Установка:** скачайте ZIP этого релиза, откройте архив и скопируйте папку `GuildRecruit735` в `World of Warcraft/Interface/AddOns/`. При обновлении замените старую папку. Не удаляйте настройки WTF.

**Проверки:** точный исходный тестовый предшественник `1.0.2-TEST / GR735-20261014-05` прошёл статические тесты; пользователь сообщил, что сохранение диапазона в игре работает. Сам новый релиз отличается от него только версией и метаданными, отдельного полного игрового прогона нет. Для точного релиза GitHub Actions выполняет Lua 5.1, тесты и проверку воспроизводимого ZIP. Сценарии HC, x100, межсерверного WHO и защищённых фреймов не считаются полноценно игровыми проверенными.

**Источники:** оригинальный независимый аддон под лицензией MIT, без кода SuperGuildInvite и других сторонних аддонов. Реальная загрузка WHISPER/приглашений выполняется только по ручному нажатию на кандидата.
