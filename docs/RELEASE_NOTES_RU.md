# GuildRecruit735 1.0.4 — релиз

**Legion 7.3.5 / Interface 70300** · **GR735-20261015-04** · **MIT**

Обновлён интерфейс: компактная мини-панель, пристыкованные настройки, сообщения и фильтры. Панели больше не открываются независимыми окнами по центру. Сообщения и фильтры можно держать открытыми одновременно; повторный клик переключает только выбранную панель, а закрытие настроек убирает всю связанную группу. Список игроков остаётся отдельным перемещаемым окном.

Фильтры имён и классов размещены во вкладках. Видны до четырёх строк имён, остальные прокручиваются; сохранённые фильтры не ограничены четырьмя. Сохранены все 12 классов, шесть шаблонов, ручные приглашения, история контактов и настройки персонажа/гильдии. «Очистить» сбрасывает только результаты поиска. Доки подстраиваются под доступный экран.

Пользователь проверил и принял интерфейс и фильтры на непосредственной тестовой основе; ниже — предоставленный им скриншот. В финальном install аддоне изменены только версия и build относительно проверенной основы. Полная проверка всех HC/taint/боевых и межсерверных сценариев не заявляется. Историческая ошибка CompactRaidFrame не объявляется доказанно исправленной.

![Новый интерфейс](https://raw.githubusercontent.com/JustAlex888/GuildRecruit735/v1.0.4/docs/screenshots/ui-compact-russian-1.0.4.png)

**Установка:** закрыть WoW, заменить только `Interface/AddOns/GuildRecruit735` папкой из установочного ZIP. WTF не удалять. Версию проверить `/gr735 version`.

**Проверки:** 9 Lua-файлов, RU/EN регрессии по 581 проверке, статическая проверка пакета, детерминированность и точный SHA256 установочного ZIP. Нативный CLI Lua5.1 проверяется GitHub Actions на публикуемом commit.
