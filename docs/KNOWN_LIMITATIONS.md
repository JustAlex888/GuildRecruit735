# Известные ограничения — GuildRecruit735 1.0.2

**1.0.2** — новый выпуск. Пользователь сообщил об успешной повторной проверке сохранения диапазона уровней в прямом тестовом предшественнике 1.0.2-TEST. Точный релизный ZIP отдельно в игре не проверялся; остальные сценарии имеют частичное или отсутствующее покрытие.

- **`GAME_TEST_004` (0.1.4)**: в игре наблюдались круглая кнопка мини-карты, работа ЛКМ/ПКМ, ручной список WHO, а на клиенте получателя — whisper и приглашение. Строгий порядок отображения сообщения перед всплывающим приглашением **не подтверждён**: в чате у получателя системная строка приглашения выше whisper, хотя Lua вызывает их в обратной последовательности.
- **`GAME_TEST_005` (0.1.5)**: все пять основных окон с английскими подписями и WHO 12/9 наблюдались на пользовательском скриншоте; пользователь не увидел проблем с переводом. Русский скриншот в документации относится к предыдущей **0.1.4**, не к этому же тесту. Отдельное подтверждение `/reload` и смены режима туда-обратно в клиенте не поступало.
- **`STATIC_VERIFIED_WITH_LIMITATIONS` / `PARTIAL_OBSERVATION_ONLY`**: автономные Lua-тесты RU и EN и синтаксический разбор пройдены для кода релиза, игровой прогон точного релизного ZIP 1.0.2 не проводился; изменения по сравнению с 1.0.1-TEST касаются сохранения диапазона уровней, а не механики приглашений.
- **Нативный Lua 5.1:** для 1.0.2 предусмотрена новая GitHub Actions проверка; её результат нужно оценивать отдельно от прежней 1.0.0.
- **`GAME_TEST_006` user report:** изменение уровней в настройках 1.0.1-TEST не сохранялось без явной кнопки. В 1.0.2-TEST исправлено по исходникам; пользователь впоследствии подтвердил успешную работу сохранения диапазона, без сырого лога точной сборки.
- **`TAINT_RISK_MITIGATED_STATIC / GAME_RETEST_PENDING`**: входной BugGrabber показывает блокировки `CompactRaidFrame*:Show()` с меткой GuildRecruit735. Код использовал общий Blizzard `UIDropDownMenu_*`, известный как возможный источник такого загрязнения. Новый UI не использует этот механизм; без реального повторного прогона и taint.log нельзя объявлять runtime-причину доказанной и исправленной в игре.
- **`NOT_OBSERVED`**: x100, надёжное исключение межсерверных игроков, полная WHO-полнота, все три режима HC на реальных кандидатах, восстановление нативного окна `/who` во всех ситуациях, множество simultaneous addon requests, drag/relog, гарантия сохранения настроек во всех клиентах.
- World ID **44** — конфигурация UWoW x1, **не номер порта**. Автоматическое распознавание миров по суффиксам имён не реализовано и не заявляется как существующая функция.
- Отсутствие HC-персонажа в ладдере означает **UNKNOWN**, а не доказанный обычный режим; при включённом исключении HC контакт с неизвестным требует дополнительного подтверждения.
- Лимит исходящего сообщения **255 байт** — консервативное ограничение реализации. Счётчик символов включает пробелы, а реальная серверная граница UWoW не подтверждена во всех случаях.
- `/who` может возвращать неполную выборку из-за ограничений сервера. Во время тестов рекомендуется не запускать одновременно другие аддоны, использующие WHO.
- Кулдаун на 30 дней фиксирует попытку контакта, а не только подтверждённый отказ. Между разными WoW-аккаунтами он автоматически не синхронизируется.
- Неизвестные языки клиента используют английский fallback; данные WHO и собственный текст пользователя не переводятся.

Поддерживается только ручное взаимодействие пользователя с конкретным кандидатом, без массовых приглашений, автоматических сообщений и записи гильдейских заметок.
