# Ограничения 1.0.4

Пользователь подтвердил приемлемый интерфейс и работу фильтров на непосредственном предшественнике 1.0.4-TEST. Два реальных скриншота показывают мини-панель, все три дока, редактор, фильтры и кандидатов после WHO. Версия на изображениях и SHA установленного дерева не отображены. Точная финальная 1.0.4 меняет только version/build метаданные относительно этого предшественника; отдельного полного игрового прогона именно нового ZIP нет.

- Нет полного игрового доказательства всех переключений/Esc/переноса/UI scale, сохранения после reload/relog и всех локалей в новой компоновке. Существуют scoped статические тесты и пользовательская приёмка.
- Старые CompactRaidFrame*:Show() protected-action ошибки не объявляются доказанно исправленными; общие Blizzard UIDropDownMenu globals не используются.
- Полные HC, x100, cross-realm WHO и все боевые сценарии не сертифицированы. World44 — исходная x1 настройка. Отсутствие в HC ладдере не доказывает NORMAL; UNKNOWN требует подтверждения в исходном безопасном режиме.
- WHO может возвращать ограниченные результаты; counters не обязаны давать total−excluded=guildless. Категории отражают существующий сканер.
- Черновики шаблонов удерживаются в памяти; только явное сохранение переносит их через reload. Лимит 255 UTF8 байт проверяется также после подстановок.
- Отправка по клиентскому API не гарантирует доставку или порядок popup на другом клиенте. Никаких массовых приглашений.
